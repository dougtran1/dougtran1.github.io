# _design

Design workspace. This folder is **ignored by GitHub Pages** (underscore prefix = Jekyll ignores), so nothing here ships to the live site. Drop stuff in as you gather it.

## What goes where

- **references/** — Inspiration screenshots, saved sites, Awwwards finds, anything you want to pull design ideas from. Name them so you remember what you liked: `vercel-hero-bold-type.png`, `pentagram-grid-asymmetric.png`, etc.

- **sketches/** — Your own wireframes, paper scans, napkin sketches, layout ideas. Raw thinking lives here.

- **brand/** — Logo files, color swatches, type specimens, anything brand-related for future iterations. Empty for now — keep-name will be `Douglas Tran` wordmark only.

- **project-assets/** — Real screenshots of your projects: Dragon's Roast logo files, HVAC email screenshots, photos you've taken, etc. Use these to replace the base64-embedded placeholders in case studies later.

## How to use this with the variations

When you drop something into `references/`, tell me which variation to pull ideas from (or all of them). I'll reference the files by name when iterating.
